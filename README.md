# NiroDrive – indirme

Kia Niro EV için Bluetooth OBD sürüş asistanı (deneme sürümü). Bu repoda sadece kurulum dosyaları (APK) bulunur.

**İndir:** [En son sürüm](https://github.com/balistic00/NiroDrive-releases/releases/latest) → `Assets` altındaki `.apk` dosyası.

**Kurulum:** APK'ya dokun, telefon sorarsa "bilinmeyen kaynaklardan yüklemeye izin ver" seçeneğini aç. Önceki NiroDrive sürümünün üzerine kurulur, veriler silinmez.

**Güncelleme:** v1.9.0 ve sonrası yeni sürüm çıktığında uygulama açılışta haber verir; "Güncelle" demen yeterli.

Gerekenler: Android 8+, ELM327 uyumlu Bluetooth OBD adaptörü (ör. Vgate iCar Pro). Uygulama araca komut göndermez, sadece veri okur. Değerler tahminidir; aracın göstergesi esastır. Kia ile bağlantısı yoktur.
